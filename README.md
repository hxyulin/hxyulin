- 🔭 **Now:** [hadris](https://github.com/hxyulin/hadris), a pure-Rust storage stack — filesystems, block devices, partitions, archives, and disk images across `std` and `no_std` — 1,000+ commits and counting [![hadris stars](https://img.shields.io/github/stars/hxyulin/hadris?style=flat-square)](https://github.com/hxyulin/hadris/stargazers)
- 🧩 **Around it:** a from-scratch POSIX kernel ([hadron](https://github.com/asterism-labs/hadron)), a rendering API built directly on wgpu ([astrelis](https://github.com/hxyulin/astrelis)), and a declarative desktop UI framework rendered with it ([rxui](https://github.com/hxyulin/rxui))
- 🌱 **Exploring:** proving Rust code panic-free from MIR ([mir-check](https://github.com/hxyulin/mir-check)), diagrams as code ([layup](https://github.com/hxyulin/layup)), FPGAs & Verilog, hardware emulation, chess engine programming
- 💬 **Ask me about:** kernels, filesystems, `no_std` Rust, static analysis of Rust, build tooling for bare-metal targets, and debugging tools for embedded firmware

### 🤖 Robotics

Tooling I build for my university's RoboMaster team.

| Project | What it is |
| --- | --- |
| [rm-simulator](https://github.com/trident-rm/rm-simulator) | First-person RoboMaster field simulator in Rust and Bevy, built from the RMUC 2026 field CAD |
| [tuning-tools](https://github.com/hxyulin/tuning-tools) | Firmware tuning studio: inspect live variables, plot telemetry, and tune parameters over SWD without halting the target |
| [datavis-rs](https://github.com/hxyulin/datavis-rs) | Real-time embedded data visualization over SWD: live plots, ELF/DWARF symbols, Rhai scripting |
| [rm-map-tools](https://github.com/hxyulin/rm-map-tools) | Exports competition field CAD into the simulator's field package |
| [herkules](https://github.com/trident-rm/herkules) | Self-hosted identity platform and monorepo for the team's internal apps, running at [herkules.dev](https://herkules.dev) |
